# أفراح العايد — متجر تجريبي

متجر عربي باتجاه RTL، مبني بـ HTML وCSS وJavaScript دون الحاجة إلى بناء أو تثبيت حزم.

## التشغيل

شغّل خادم ملفات داخل المجلد، مثل `python -m http.server 4173`، ثم افتح `http://localhost:4173`.

## الوظائف

بنرات قابلة للتبديل، أقسام، بحث، تصفية وترتيب، تفاصيل المنتجات، مفضلة، سلة مع تعديل الكميات، وإتمام طلب تجريبي. تحفظ السلة والمفضلة في localStorage. لا توجد مدفوعات أو طلبات حقيقية أو خادم يجمع بيانات العملاء.

## النشر

مناسب لـ GitHub Pages: اختر الفرع `main` والمجلد الجذر في Settings → Pages.
