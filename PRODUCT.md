# Product

## Platform
web

## Stack
Delegated by the user. Static HTML/CSS/JavaScript for a lightweight GitHub Pages demo.

## Purpose
Arabic beauty storefront called أفراح العايد, with a smooth soft interface using the supplied banners, category icons and logo. User authorized invented demo products and GitHub publication.

## Constraints
Preserve source assets. Demo catalog, cart and checkout; no real payment processing. Arabic RTL. Prices in SAR are an implementation assumption based on the supplied Saudi Arabic branding, not confirmed commercial data.
